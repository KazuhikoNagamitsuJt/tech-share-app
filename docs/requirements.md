# 要件定義

## 1. 機能要件（6つの機能）

- **記事一覧:** 投稿された記事をすべてカード形式で一覧表示する機能。
- **記事詳細:** 選択された記事の本文をMarkdown形式で1件表示する機能。
- **記事投稿:** 新しい記事（タイトル・本文）を作成し、プレビューをリアルタイム更新して投稿する機能。
- **記事編集:** 既存記事のタイトル・本文を修正する機能（見出しとボタンを「記事の編集」「更新する」に切り替え、作成日は不変とする）。
- **記事削除:** 確認ダイアログを表示した後に記事を削除する機能。
- **記事検索:** タイトルおよび本文のキーワード（大文字・小文字を区別しない）で記事をリアルタイムに絞り込む機能。

## 2. 記事のデータ項目（5フィールド）

| フィールド名 | データ型        | 説明                       | 例                        |
| :----------- | :-------------- | :------------------------- | :------------------------ |
| `id`         | 文字列 (string) | 記事を一意に識別するID     | `"1"`                     |
| `title`      | 文字列 (string) | 記事のタイトル             | `"React Hooksの完全理解"` |
| `content`    | 文字列 (string) | 記事の本文（Markdown形式） | `"## useStateとは..."`    |
| `author`     | 文字列 (string) | 投稿者名                   | `"Tech Taro"`             |
| `createdAt`  | 文字列 (string) | 記事の作成日               | `"2026-05-14"`            |

## 3. APIエンドポイント案（5本）

| HTTPメソッド | エンドポイント（URL） | 操作内容                      |
| :----------- | :-------------------- | :---------------------------- |
| `GET`        | `/articles`           | 記事を全件取得する            |
| `GET`        | `/articles/:id`       | 指定したIDの記事を1件取得する |
| `POST`       | `/articles`           | 新しい記事を新規作成する      |
| `PATCH`      | `/articles/:id`       | 指定したIDの記事を更新する    |
| `DELETE`     | `/articles/:id`       | 指定したIDの記事を削除する    |
